# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - Initial Release

### Added
- Fusion of best practices from 23 Douyin spark projects into a single self-hosted platform
- 7 notification channels: Telegram, Email, Slack, Discord, Webhook, Bark, ServerChan
- Dark theme support with automatic system preference detection
- 5-layer search system for comprehensive content discovery
- 12-keyword rate limit detection to prevent triggering platform restrictions
- Self-hosted deployment with Docker and Docker Compose support
- RESTful API for programmatic access to all features
- Real-time monitoring dashboard with configurable alerts
- Multi-account management with session persistence
- Automated data collection and export capabilities
- Comprehensive logging and error tracking
